Nhằm đảm bảo tính minh bạch, ghi nhận đúng tiến trình làm việc và bảo vệ kết quả học tập của chính mình, yêu cầu sinh viên thực hiện nghiêm túc theo các quy định kỹ thuật sau đây:
1. Quy định bắt buộc về công cụ soạn thảo
Chỉ sử dụng Google Docs: Sinh viên bắt buộc phải tạo một file mới hoàn toàn và gõ trực tiếp toàn bộ nội dung bài làm trong Google Docs.
Cấm tuyệt đối: Không làm bài trên giấy, không soạn thảo bằng Microsoft Word, Notepad, ChatGPT hay các phần mềm khác rồi dán (copy-paste) toàn bộ nội dung vào phút cuối. Mọi hành vi dùng văn bản có sẵn để dán vào hệ thống sẽ bị phát hiện qua lịch sử phiên bản (Version History) và không được công nhận kết quả.
2. Thiết lập quyền chia sẻ file Google Docs
Sinh viên mở quyền chia sẻ file Google Docs ở chế độ: "Bất kỳ ai có đường liên kết đều có thể chỉnh sửa" (Anyone with the link can edit).
Lưu ý: Không cần chia sẻ file qua email của giảng viên, chỉ cần dùng link có quyền chỉnh sửa này đưa vào file nộp.
3. Quy cách và hình thức nộp bài
Nơi nộp bài: Sinh viên bắt buộc nộp bài trực tuyến thông qua classroom. Tuyệt đối không nhận bài qua email hoặc bất kỳ hình thức nào khác.
Định dạng file nộp: Nộp 01 file PDF duy nhất với tên M01 - BatchGD_Regression_HoTen_MaSV.pdf. Trang đầu tiên của file PDF bắt buộc trình bày đầy đủ các thông tin sau:
Tên học phần (Môn học): [...]
Lớp môn học: [...]
Họ và tên sinh viên: [...]
Mã số sinh viên (MSSV): [...]
Đường liên kết (Link) Google Docs: [Dán link Google Docs đã cấp quyền Editor tại đây]
4. Quy định sau khi nộp bài
Sau thời hạn nộp bài trên hệ thống (Deadline), sinh viên tuyệt đối không được chỉnh sửa, bổ sung hoặc thay đổi bất kỳ nội dung nào trong file Google Docs.
Hệ thống sẽ kiểm tra mốc thời gian sửa cuối cùng trên Google Docs so với thời gian nộp file PDF. Mọi tác động vào nội dung file sau thời gian nộp bài đều bị xem là vi phạm quy định.
